## ✨ Features

- **Cinematic Animations**: Seamless, staggered scroll reveals powered by **GSAP** & **ScrollTrigger**.
- **Modern Layouts**: Includes a sleek floating pill Navbar, a bento-grid Services section, and a sticky split-screen Process workflow.
- **Micro-Interactions**: Beautiful hover effects that bring the interface to life (expanding gold dividers, floating tech icons, magnetic buttons).
- **Luxury Aesthetics**: Uses a cohesive, high-end color palette (Cream, Deep Purple, and Gold) paired with beautiful editorial serif typography.
- **Fully Responsive**: A flawless, app-like experience from mobile screens to ultrawide desktop monitors, complete with a custom full-screen mobile menu overlay.

## 🛠️ Tech Stack

- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Tech Stack Icons](https://tech-stack-icons.com/)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/yash-portfolio.git
   cd yash-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the portfolio in action.

## 📁 Key Components

The codebase is highly modularized into several high-end, animated components, located in the `components/` directory:

- `Hero.tsx`: The striking, full-screen entrance to the site.
- `BuiltFor.tsx`: Elegant GSAP staggered typography reveals.
- `Work.tsx`: Showcase of recent premium projects.
- `Marquee.tsx`: Infinite scrolling tech stack with smooth grayscale-to-color hover effects.
- `Services.tsx`: A beautiful bento-grid layout with 3D flip-up GSAP reveals.
- `WhyMe.tsx`: Trust-building section featuring giant background typography and smooth scroll reveals.
- `Process.tsx`: A sticky split-screen layout detailing the development workflow.
- `About.tsx`: A two-column editorial layout detailing experience and philosophy.
- `CTA.tsx`: A massive closing block featuring an infinite array of floating background tech icons.
- `Navbar.tsx`: A floating, glassmorphic pill navbar with a custom framer-motion mobile overlay menu.
